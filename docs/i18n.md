# Internationalization (i18n)

This document describes how Fractale handles internationalization and language selection for serving localized content.

## Supported Languages

Fractale currently supports the following languages:

| Code | Language |
|------|----------|
| `en` | English (default) |
| `fr` | French |

The available languages are defined at build time via the `langsAvailable` variable in `web/fileserver.go`. The Makefile replaces this value during the build process.

## Language Selection Priority

When serving content, the file server determines the user's language using the following priority order:

1. **User Account Setting**: If the user is logged in, their saved language preference (`User.lang` field) is used.
2. **Cookie**: If a `lang` cookie is present and contains a valid language code, it is used.
3. **Browser Accept-Language Header**: The server parses the `Accept-Language` HTTP header and selects the first supported language from the user's preferences.
4. **Default Language**: Falls back to English (`en`) if no other preference is found.

## How It Works

### File Server Logic (`web/fileserver.go`)

The `FileServer` function handles static file requests with language-aware routing:

1. **Direct File Requests**: If the requested path exists as a file on the filesystem, it is served directly (e.g., CSS, JS, images).

2. **Language Path Detection**: If the URL path starts with a language code (e.g., `/fr/dashboard`), the server:
   - Sets a `lang` cookie with that language (valid for 90 days)
   - Redirects to the path without the language prefix

3. **Index Serving**: For all other requests, the server determines the appropriate language and serves `{lang}/index.html` from the public directory.

### User Language Preference

The language preference is stored in the `User` model as a `Lang` enum:

```graphql
enum Lang {
  EN
  FR
}
```

Users can update their language preference through their account settings. This preference is persisted in the database and takes precedence over cookies and browser settings when the user is authenticated.

## Adding a New Language

To add support for a new language:

1. Add the new language code to the `Lang` enum in `schema/graphql/fractal6.graphql`
2. Update the `langsAvailable` build variable in the Makefile to include the new language code (separated by underscore, e.g., `en_fr_de`)
3. Create the corresponding localized `index.html` and static assets in the public directory under `{lang}/`
4. Regenerate the GraphQL models

## Cookie Details

| Property | Value |
|----------|-------|
| Name | `lang` |
| Path | `/` |
| Max-Age | 7776000 seconds (90 days) |

## Implementation Details

- Language codes are lowercase (`en`, `fr`) when used in paths and cookies
- The `Lang` enum values are uppercase (`EN`, `FR`) in the database/GraphQL layer
- The `golang.org/x/text/language` package is used to parse the `Accept-Language` header
