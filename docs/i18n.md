# Internationalization (i18n)

The backend's only i18n concern is picking which localized `index.html` to serve.
All of it lives in `web/fileserver.go`.

Available languages are a build-time variable (`langsAvailable`, underscore-separated,
substituted by the Makefile). Currently `en` (default) and `fr`.

## Language selection

`FileServer` resolves the language in priority order:

1. The logged-in user's `User.lang` preference
2. A `lang` cookie
3. The `Accept-Language` header (parsed with `golang.org/x/text/language`)
4. English

Requests for an existing file on disk are served directly. Everything else serves
`{lang}/index.html`.

Codes are lowercase in paths and cookies, uppercase in the GraphQL `Lang` enum.

## Language switch

Each language is a separate UI build, so switching is a full reload to `/{lang}/<path>`.
The server sets the `lang` cookie (90 days) and redirects to the bare path:

- **302, not 301**: the redirect sets a cookie, it must hit the server every time.
- **Timestamp param**: both language shells share the same URL, a 304 would serve the old one.
- **Sanitized target**: leading `/` and `\` are stripped (no open redirect).

UI side (`updateLang` in `fractal6-ui.elm/assets/js/bulma_drivers.js`):

- The Settings GoBack target is kept in history across the reload.
- The old page reloads itself if restored from bfcache, so going back never shows the old language.

## Lexicon

Organisations can rename the UI vocabulary ("Tension" to "Ticket", ...).

- Stored in `Node.lexicon` on the root node, as a JSON-serialized dict
  (`{"Tension":"Ticket","tension":"ticket"}`). Case variants are separate keys.
- Written by owners through `POST /auth/setlexicon` (`{ nameid, val }`).
- Used by the UI at render time (`fractal6-ui.elm/docs/lexicon.md`) and by the tensions
  export sheet name (`tensionTerm` in `web/handlers/q_tensions.go`).

## Adding a language

Add it to the `Lang` enum in `schema/graphql/fractal6.graphql`, extend
`langsAvailable` in the Makefile, ship the localized assets under `{lang}/` in the
public directory, and regenerate the models.
